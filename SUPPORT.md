# Support

- **Questions and usage help:** ask in [GitHub Discussions](https://github.com/ottramst/terraform-provider-vaultwarden/discussions).
- **Bugs and feature requests:** open an [issue](https://github.com/ottramst/terraform-provider-vaultwarden/issues/new/choose) using one of the templates.
- **Security vulnerabilities:** see [SECURITY.md](SECURITY.md); do not open a public issue.

This provider is maintained on a best-effort basis by volunteers. Check the
[support policy](README.md#support-policy) for the Vaultwarden versions it supports.
