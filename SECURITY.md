# Security Policy

## Supported versions

Security fixes are released for the latest minor version of the provider only.

| Provider version | Supported          |
| ---------------- | ------------------ |
| latest release   | :white_check_mark: |
| older releases   | :x:                |

The provider supports the two newest Vaultwarden minor releases; see the
[support policy](README.md#support-policy).

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/ottramst/terraform-provider-vaultwarden/security/advisories/new).
Include a description of the issue, the affected provider and Vaultwarden versions, and steps to
reproduce it if possible.

You can expect an acknowledgement within a week. Once the issue is confirmed, a fix is released as soon
as practical and the advisory is published afterwards, crediting the reporter unless they prefer otherwise.

Vulnerabilities in Vaultwarden itself should be reported to the Vaultwarden project, following
its [security policy](https://github.com/dani-garcia/vaultwarden/security/policy).
